# JMeter Performance Engineering Framework

Performance testing framework using Apache JMeter, InfluxDB and Grafana.

## Components

- Apache JMeter
- InfluxDB 2.x
- Grafana
- Git
- Jenkins

## Execution

Tests are executed using JMeter CLI with runtime parameters.

## Metrics

- Average response time
- P90
- P95
- P99
- Throughput
- Error percentage
- Request count
